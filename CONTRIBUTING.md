# Contributing

Thanks for helping out. Keep changes small and focused.

1. Fork the repo and create a branch from `main` (`feat/...` or `fix/...`).
2. Set up locally: `npm install`, `cp .env.example .env`, `npm run seed`, `npm run develop`.
3. Make your change. Run `npm run build` before opening a PR.
4. Update `docs/API.md` if you change an endpoint or content type.
5. Open a pull request describing what and why.

Use conventional commit messages (`feat:`, `fix:`, `docs:`). For bugs and ideas, use the issue templates. Be respectful and constructive.
